THE SCIENCE BEHIND THE PRACTICAL

Search time, handling time, evidence.

A humane way to investigate predation and experimental design.

What are we measuring?

A functional response describes how consumption by one predator changes with prey density over a defined period. Here, your visual search and clicks supply the searching behaviour; a fixed delay represents handling.

Holling’s classic experiments included artificial predator–prey tasks. This activity follows that teaching principle: the response emerges from your actions, rather than from an imposed curve.

Holling type II · constant prey densityNe = a N T / (1 + a h N)

Ne = expected number consumed; N = prey per arena; T = trial seconds; a = search coefficient (arena/s); h = handling seconds per prey. The theoretical high-density limit is T/h when h > 0.

Type I is approximately linear before saturation; type II rises with a diminishing slope; type III is sigmoid. A shape alone is not a statistical diagnosis. The presets change the mechanisms students experience; they do not guarantee that a student’s observations will trace a particular curve.

Why does prey replacement matter?

In removal trials, prey become less abundant as you feed. Rogers’ random-predator equation accounts for this depletion:

Type II · prey not replacedNe = N0 [1 − exp{−a(T − h Ne)}]

For Type II, the results panel solves this equation in removal mode and uses Holling’s equation in replacement mode. Type I sets handling to zero. For Type III, the depletion calculation also allows capture success to fall as prey are removed. Keep these designs separate when analysing the data.

What do the response presets change?

Switching the preset automatically sets handling time and turns density-dependent capture on or off. Species, trial length, density series, replicates and other conditions stay as you chose them. Create a new experiment to record the new treatment.

PresetHandlingAccurate clicks
Type I0 sAlways capture
Type II1 s initiallyAlways capture
Type III1 s initiallyCapture chance rises with current prey density

Type I removes the handling constraint; human search and pointing still take time. Type II adds a fixed handling delay, which can limit consumption at high densities. You can adjust that delay in Type II and III.

A transparent Type III mechanism

Each accurate click has probability p(N) = N/(N + K) of capturing an aphid, where N is the number currently on the leaf and K is the half-success density (initially 20). Thus 5, 20 and 80 aphids give capture chances of 20%, 50% and 80%. Failed attempts leave the aphid in place and do not start handling. The live percentage shows the current chance.

This is a chosen teaching rule for increasing capture efficiency with density, not a measured parameter for ladybirds or lacewings. It does not track a predator’s experience. Learning and prey switching can contribute to Type III responses, but learning can also produce other shapes: see Bruzzone and colleagues (2022).

Type III reference · constant prey densitya(N) = a N/(N + K)
Ne = a(N) N T / [1 + a(N) h N]

The model assumes that encounter rate is proportional to prey density. For removal trials it integrates this rate as prey decline. The overlay remains an illustration, not a fit or a promise about the data collected by human students.

Run a computer-lab practical

  1. Predict. Sketch consumption against prey density. What should a longer handling time change?
  2. Practise. Use the unrecorded 10-second trial to get used to searching and pointing.
  3. Collect. The default is five densities, three replicate blocks and 20 seconds per trial: five minutes of active searching and handling.
  4. Compare. Create a second experiment with one changed condition, such as 2 s handling. Use the same observer, device, zoom, target size and other settings.
  5. Analyse. Plot raw trials, means and variability. Export to R, jamovi or a spreadsheet for further analysis.
  6. Evaluate. Discuss depletion, learning, fatigue, visibility and why a click experiment cannot establish which natural enemy controls a crop pest best.

A fair and accessible comparison

Use anonymous group codes. Students can share searching, recording and interpretation roles. Touch and large-target trials are supported, but their results should not be pooled uncritically with mouse trials. For students unable to use a visual pointing task, analyse a partner’s exported observations.

Trial order is randomised within each replicate block. Aphid positions change each time and targets do not overlap. Aphids stay visible while the handling bar fills; further captures are blocked. Students can plan their next click during handling, so visual search and handling are not strictly exclusive. Keep that limitation in mind when comparing the game with theoretical models. Light and dark mode change the interface only; the leaf and prey colours stay the same. Switching tabs or resizing the arena discards the unfinished attempt.

Species and model boundaries

Choose three UK crop pests: peach–potato aphid (Myzus persicae), black bean aphid (Aphis fabae) and pea aphid (Acyrthosiphon pisum). The natural-enemy scenarios are a fourth-instar seven-spot ladybird (Coccinella septempunctata) or a third-instar green lacewing (Chrysoperla carnea group).

Species choices provide biological context. Both predators use the same preset rules: Type I has no handling delay, while Type II and III initially use 1 s. Aphid icons have the same target size; colour and visibility can still change human search performance. Images are schematic and are not identification guides.

Published estimates depend on prey and predator stage, temperature, arena and experimental method. Kayahan (2021), for example, reports third-instar lacewing handling estimates of 23.62 min for A. fabae and 21.89 min for A. pisum. Those are estimates from that study, not universal species constants or settings used here.

No temperature response, hunger, digestion, predator movement or chemical cues are simulated. The Type III capture rule is an illustrative density effect, not a calibrated escape or learning model for these species. Changing the predator label alone does not change capture mechanics. Use the handling control to test an explicitly stated hypothesis.

Replacement, reduction and reflection

This activity replaces live predation for learning about functional responses. It provides repeated practice without maintaining or killing live insects. It does not reproduce every skill or observation available from a live-animal practical. Discuss what is gained, what is lost, and which learning outcomes require another approach.
